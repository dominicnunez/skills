Changes: Allows valid unchanged evidence reuse; distinguishes focused proof from full completion; preserves final-head review requirements. Matches cost claims to complete workloads, requires timeout diagnosis before budget changes, and treats delegated audit results as scoped evidence. Adds a conditional contract-evidence gate for cross-boundary changes: independent identity channels, source/cache proof, comparable measurements, independent coverage audit, and explicit hold decisions for missing evidence. Requires evidence handoffs to preserve captured stdout, stderr, and exit status when needed; remove secrets and private material the storage destination or recipient is not authorized to receive; label redactions as sanitized and summaries as summaries while retaining the observed exit status and diagnostic meaning; never reconstruct output and call it raw or describe sanitized evidence as raw; and report missing required evidence with a fresh capture only when needed. Requires non-obvious tool options and settings to be verified at the owning operation of the pinned real tool in a permitted fixture; mocked acceptance and settings readback in another mode or directory do not prove enforcement, and unavailable operation evidence remains an explicit gap. For configuration loaders that can fall back to defaults, requires an observable fixture setting that differs from fallback and inspection of diagnostics and effective behavior; identical defaults or exit zero do not prove application. Requires needed delegated evidence to reach the recipient through an authorized inspectable channel, without mandating shared storage or extra persistence when accessible runtime output is sufficient. Distinguishes declaration or inventory selection checks from executed consumer coverage for applied-configuration regression claims. Connects cached compiled-test evidence to the actual executable and intended source/features; recommends separate Cargo target directories across worktrees, checks new cases in the executable test list, rejects missing or fully filtered cases, and records executable identity for result reuse.
